## 4 发现的问题和调整建议

严重性按对模型或权限实现的影响划分，不代表运行系统已存在缺陷。

| 编号 | 影响 | 发现与出处 | 本阶段调整及后续要求 |
| --- | --- | --- | --- |
| R-01 | 路径与可追踪性 | 实际目录 sepecs 与指定 specs 不符 | 保留原件，建立 specs 文档并正确相对链接，不覆盖用户资料 |
| R-02 | 高，教师越权风险 | “负责班级或课程”没有完整范围算法；考勤矩阵只写负责班级 | 分动作说明范围；A-04/A-21 处理未决并集和历史关系，不用单一并集给全部业务授权 |
| R-03 | 高，档案写权限 | FR-05、权限矩阵、UC-03 对教师修改权描述不一致；接口行合并 GET/POST | 新增学生仅管理员；教师编辑字段待 A-05，未确定前不开放写入 |
| R-04 | 高，课程写权限 | UC-04 把课程维护和选课合为一项，可能误读教师可创建课程 | 用例图按课程维护、课程查看、选课拆分；教师无课程维护权；新增选课的学生范围待 A-22 |
| R-05 | 高，成绩完整性 | 缺分拒绝保存与附录空分项/空总分冲突；30/70 明确属假设 | 区分未评分选课与成绩提交；A-02/A-06 决策后确定草稿、舍入和重算策略 |
| R-06 | 高，归档数据模型 | “停用/归档”未有独立 Student 字段；学籍只有四状态 | 不增第五状态、不把账号停用等同归档；A-07 决定数据模型与账号联动 |
| R-07 | 高，审计结构缺口 | 第 4.4 要求所有写入有操作者时间，但多数表无字段，业务日期不等于录入时间 | A-08 决定审计字段或日志方案；本阶段不虚构字段或宣称已覆盖审计 |
| R-08 | 高，通知结构缺口 | FR-22 提拟发送状态，ParentContactLog 无结构化状态或渠道字段 | A-09 决定即时提示还是可查询状态及存储；result 不能冒充发送状态；无真实网关 |
| R-09 | 高，空值与约束 | 11 个字段仅写 FK，缺 NN；包含选课/考勤组合唯一字段 | 原文保留并标 NN待定；图标 1（建议）；A-13 后统一明确 DDL |
| R-10 | 高，历史授权 | Course 单 teacher_id 而 Enrollment 按学期；Student 只有当前 class_id | A-10/A-21 决定是否接受当前关系简化及历史访问，或明确变更模型；不擅加教学班/任教历史表 |
| R-11 | 中，关联一致性 | 联系记录同时存学生和家长，独立 FK 不保证同一学生；parent_id 可空 | 补充服务端归属校验，A-11 决定空对象语义及是否数据库组合约束 |
| R-12 | 中，学生隐私边界 | 学生奖惩“只读本人（按策略）”未定，核心个人查询未包括奖惩 | A-12 待确认；学生只确认资料、课程、成绩、考勤和本人摘要 |
| R-13 | 中，统计口径 | 出勤率是建议；零分母、平均分学期和缺分、人数字段过滤不明 | A-03/A-15 记录建议与待决项，不制造数值或量化性能门槛 |
| R-14 | 中，枚举与默认值 | 性别、学期格式、节次、学分限制和字段默认值无完整定义 | A-14/A-16；保留四学籍语义和已明确考勤、奖惩英文值，不发明封闭字典 |
| R-15 | 中，历史删除 | 原案要求保留学生历史，却未指定所有 FK 的 ON DELETE，课程又要求 CRUD | A-17 建议阻止删除仍被引用对象；不静默设置 ORM 级联删除或全表软删除字段 |
| R-16 | 中，主要联系人 | is_primary 不代表原案已要求每生唯一主要联系人 | A-19 决定后再加约束，不根据命名扩展规则 |
| R-17 | 中，图文字段不一致 | 原类图/ER 用 date 简写，省略部分字段和账号唯一档案关联；班主任、课程教师画成固定 1 | 统一 attendance_date；类图/ER 均列 73 字段与 16 FK，明确 0..1 和唯一关联；未决必需性有标记 |
| R-18 | 中，职责和流程 | 原顺序图没有 ORM 对象而通信图有，编号不一致；正常流程省略异常；模型含概念方法 | 三流程图统一职责、参与对象、消息及失败回滚；概念认证和成绩算法归 Service；不强制新增 Repository 层 |
| R-19 | 低，状态解释 | 学籍终态可能被误解为删除；恢复或历史导入未规定 | 按原状态图保留迁移并说明保留历史；A-20 处理例外，不发明审批和恢复流程 |
| R-20 | 环境与验收真实性 | 空目录、全局包不齐，且原案测试表全为待执行 | 记录实际环境和未执行状态；文档检查与业务测试分开，不宣称可运行或测试通过 |
