# 阶段 6 考勤、奖惩与家长联系决策

以下规则为阶段 6 新增课程设计假设，复用既有模型、约束与阶段 4B 的 TeacherScope。

| 决策 | 阶段 6 规则 |
| --- | --- |
| A-03 | 状态沿用 present、late、absent、leave。出勤率为 (present + late) ÷ (present + late + absent) × 100%，显示两位小数。请假不进入分母。分母为零显示“无可统计数据”。统计以实际登记为准。 |
| A-04 | 管理员拥有全局权限。班主任按当前 SchoolClass.homeroom_teacher_id 和 Student.class_id 管理本班学生，课程关联无额外授权。学生限本人考勤查询与统计。 |
| A-12 | 学生奖惩查询与写入默认拒绝，待明确授权后再开放。 |
| A-09 | 操作者显式提交时才调用 create_simulated_notification()，渠道限 sms、email，状态为 simulated，保存接收对象快照。页面标明“模拟通知，未实际发送”。 |
| A-14 | period 非空且最长 30 字符，可自由填写。考勤状态、奖惩类型和联系方法沿用既有枚举。 |

| 动作 | 管理员 | 教师 | 学生 |
| --- | --- | --- | --- |
| attendance_read | 全局 | 当前本班 | 本人 |
| attendance_write | 全局 | 当前本班 | 禁止 |
| reward_read、reward_write | 全局 | 当前本班 | 禁止 |
| parent_contact_read、parent_contact_write | 全局 | 当前本班 | 禁止 |
| notification_read、notification_create | 全局 | 当前本班 | 禁止 |

考勤以学生、日期和节次唯一。日期筛选包含起止日。联系人日期和通知记录以 UTC 展示和筛选。班主任权限随学生当前班级关系变化，历史归属授权留待后续设计。

新建联系时，有家长档案则保存该家长当时的姓名与电话，否则填写联系人姓名及可选电话。编辑联系可更新方式、时间、内容、结果，保留学生、家长和联系人快照。旧记录若缺姓名或电话快照，页面标明该字段未保存。模拟通知可选择所属家长，也可填写临时联系人及对应渠道的接收地址。

创建时登记人与创建人来自登录账号。考勤编辑记录本次登记者，奖惩和联系保留原创建者，实际编辑人写入审计。业务写与审计共用 SQLite 写锁和一次提交。审计字段采用白名单，记录业务元数据前后值及变动字段名，联系姓名、电话、邮箱、接收对象快照及备注、事由、联系和通知正文仅保存在业务记录。

阶段 6 沿用既有 13 张领域表。考勤、奖惩、家长联系保留历史记录，模拟通知只允许创建与查询。
