# 阶段 5 课程、选课与成绩决策

| 决策 | 阶段 5 规则 |
| --- | --- |
| A-02 | 平时成绩占 30%，考试成绩占 70%。Service 使用 Decimal 运算，再以 ROUND_HALF_UP 把总分舍入到两位小数。三项分数按现有 Float 字段存储，展示固定两位。 |
| A-06 | 创建选课时三项成绩均为 NULL。正式保存需两项有限数值，含 0 和 100。部分草稿与清空成绩留待后续，未评分与 0 分分别显示。 |
| A-10 | Course.teacher_id 表示现任教师。教师仅在 ACTIVE_SEMESTER 读取和编辑本人当前授课课程的成绩。管理员可维护所有学期。现有历史选课名单可按学期查看，名单不展示历史成绩。历史任教权限仍待设计。 |
| A-22 | 管理员可为任意现有学生和现有课程创建选课。教师须同时满足有效绑定、当前授课、学生当前属于本人班主任班级和配置学期。候选来自 Student 和 SchoolClass，已有 Enrollment 不作为新增选课前提。学生不能自行选课。 |

`ACTIVE_SEMESTER` 从环境或应用配置读取，默认 `2026-Fall`。学期是非空且最多 30 字符的标签。成绩与选课列表默认显示配置学期，过滤器列出当前角色范围内的学期。管理员和学生可选择全部学期并看到记录所属学期。阶段 4B 的最小身份名单继续跨学期去重。

| 动作 | 管理员 | 教师 | 学生 |
| --- | --- | --- | --- |
| course_read | 全局 | 当前本人授课 | 本人选课涉及课程 |
| course_manage | 新增、修改、指定授课教师 | 禁止 | 禁止 |
| enrollment_read | 全局 | 当前本人课程按学期名单 | 本人选课 |
| enrollment_create | 现有课程与学生，可指定学期 | A-22 四条件 | 禁止 |
| grade_read | 所有学期 | 本人当前课程和配置学期 | 本人所有学期 |
| grade_write | 所有学期 | 本人当前课程和配置学期 | 禁止 |

课程详情人数由可访问的选课记录聚合。学生只看到本人的选课状态。现有课程、选课和成绩历史保留，课程换教师只改变 Course.teacher_id。新页面使用既有 academics Blueprint，保留旧路由。学分只校验为可存储的有限数值，暂无业务门槛。

服务层在 SQLite 写事务取得锁后，重新校验操作者、当前任教关系和目标对象。外层提交业务与审计。成绩快照使用 Enrollment 主键和三项成绩的前后值，记录操作者和 UTC 时间。数据库、依赖及阶段 4B 权限接口沿用。
