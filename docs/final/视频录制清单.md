# 视频录制清单

目标时长 5–8 分钟，教师明确要求其他时长时按课程要求调整。镜头时间和旁白见[视频演示脚本](视频演示脚本.md)。

## 录制前

- 用[Windows 课堂部署说明](../deployment/windows_setup.md)建立独立虚构数据实例，设置 `APP_ENV=demo`、独立 `SMS_INSTANCE_PATH` 和 `ACTIVE_SEMESTER=2026-Fall`。从空库依次迁移、初始化角色、创建课堂管理员、生成演示资料。
- 在用户管理创建临时课堂教师及学生账号，并绑定档案。让教师担任一个班级的班主任和一门演示课的授课教师。另准备一名非本班学生，供权限检查。
- 准备角色切换用的独立浏览器会话。关闭自动填充、密码保存提示、无关标签页和桌面通知。输入凭据时暂停画面或通过剪辑切除。
- 使用虚构身份和联系方式。示例 `E8-S001`、课堂学生甲、课堂验收班、课堂验收教师、课堂监护人、`guardian-v8@example.invalid`。录制新增档案和课程可用 `V9-S001` 与 `V9-C001`，复录时改用未占用编号或恢复专用演示实例。
- 展示前先核对当前学期、课程的授课教师、家长归属和名册。检查已有阶段 8 [pytest 日志](../reports/stage8_pytest.txt)及[浏览器记录](../reports/stage8_browser.json)。

## 录制中

- 桌面镜头以 1440 × 900 为基准，手机镜头以 390 × 844 视口核对。将浏览器内容调整到清晰可读。
- 在页面中实际新增学生、课程及选课，输入 80 和 90、保存并停留到 87.00 显示。
- 用班主任账号实际保存考勤、奖励、家长联系和模拟邮件。展示模拟通知提示并查看管理员审计。
- 展示同角色的合法和拒绝操作。教师跨班和学生访问管理路由以实际 HTTP 403 页面为准。
- 旁白可以现场讲解，也可以使用已核对的普通话解说词后期配音。保持纯净音轨，避开无关界面和个人资料。

## 导出后

- 使用 MP4 容器、H.264 视频和 AAC 音频。顺序播放并抽查开头、角色切换、业务写入、拒绝页及结尾。
- 确认语音可辨、页面清晰、时长合规；确认画面未出现密码、私人数据或密钥。
- 将实际录制并验证的成片放入最终提交包的 `video/`。复录可在 Windows 使用 Xbox Game Bar 等本地录屏工具，仅选取课堂浏览器窗口。
