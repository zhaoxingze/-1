# 阶段 7 管理员功能、统计及界面决策

以下规则为阶段 7 新增课程设计决策。

## 账号与审计

- 角色固定为 admin、teacher、student，选择已有 Role 字典项。教师、学生必须各绑定对应的一个档案，管理员不绑定档案。档案最多绑定一个账号，停用账号仍保留绑定。
- 管理员可创建、查询、编辑账号和启停其他账号。账号启停与学籍、档案归档独立。管理员本人保留启用的管理员角色与空档案绑定。写入时使用 SQLite 写锁并重新验证权限与可用管理员数量，保留至少一个可用管理员。
- 密码沿用 Werkzeug 哈希及现有密码重置流程。启停、角色或绑定变化同事务写审计，使用最新相关审计 ID 作为单调会话版本成分。再次启用、角色改回或重新绑定原档案时，旧会话保持失效。
- 审计页面仅管理员可读。日期采用包含起止日的 UTC 自然日。详情在既有递归清理后，只展示实体对应的安全元数据。联系信息、自由文本、通知快照和凭证不进入详情。

## A-15 统计口径

- 管理员学生总数包含全部档案。在读人数要求 enrolled 且未归档。归档人数单独汇总，教师、班级、课程计全部真实记录。
- 教师分别按当前班主任班级统计人数与考勤，按当前授课课程统计课程和成绩。教师成绩统计沿用配置学期限制。学生只能查询本人摘要、配置学期选课和完整成绩及本人考勤。
- 考勤为含今日和前 29 日的 UTC 自然日，包含起止日。仅统计实际登记，迟到计入出勤率分子，请假单列。分母为零显示“无可统计数据”。
- 课程平均分按显式学期标签过滤，默认使用配置学期。三项成绩完整的选课记录才进入平均值。无完整成绩显示“暂无数据”。
- 复用现有 13 张领域表及 SQLite 迁移。侧栏按后台认证角色及班主任范围生成，页面使用本地 Bootstrap 和既有 Jinja2。
